## 实际行为

- 手机竖屏进入对局显示横屏入口；点击请求页面全屏后请求 landscape 锁定。浏览器拒绝或缺少 API 时保留手动旋转提示。离桌释放本次取得的屏幕状态，不退出其他元素原有的全屏。Android 实机仍待验证，自动化视口旋转不代表已在实际手机锁屏成功。
- 深蓝织物桌面、桌沿、四家围桌与中央局况。三麻保持真实三席。传统原创 SVG 牌面使用筒子圆纹、竹节与一索鸟、万子和字牌；白板蓝框、红五与立体牌身。手牌、河牌、副露、和牌与指示牌共用牌面，不引入持续 WebGL 渲染或模型。
- 左上角显示真实已翻开的指示牌，其余位置是无牌值的背面；另显示按当前三/四麻规则换算的宝牌文字。里宝牌仍在和了结算按实际响应展示。
- 点击有副露的玩家信息卡打开原生只读详情，牌面 39×56；关闭按钮及 ESC 可退出，暗杠保持背面，不发送出牌命令。
- 对家身份位于右上，侧家身份固定、不因副露展开向宝牌区移动；公开副露单独有界，自身公开副露摆在私有手牌旁。私有手牌区域不包含公开副露牌值。
