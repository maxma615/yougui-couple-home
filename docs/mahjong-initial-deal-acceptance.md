# 真实起手牌序与理牌位移

日期：2026-10-10。此轮持续改善普通实时开局；未完成全部雀魂体验对齐。发布状态和正式运行版本见本文后续发布记录；当前线上版本暂为 `1709ad8`。

## 行为与边界

三麻和四麻引擎在构造规范化手牌前记录真实的 13 次起手摸牌，按实际座位返回 `initialDeal`。它只包含请求者自己的牌，没有对手手牌或剩余牌山；返回数组独立复制。有效首个操作后清除整桌开局元数据，非法或过期操作不清除，新局重新记录。四麻的临时摸牌观察方法在 `finally` 中还原，不改变随机数、抽牌次数、发牌分配或物理牌池。

只有已接受的实时开局使用该顺序，初始获取、重连、减少动效、断线或环境变化继续直接显示排序手牌。客户端逐张验证真实物理牌的多重集合，红五和普通五不能互换；缺失或不匹配的旧快照使用规范化牌序，不生成伪随机顺序。

1200 ms 开始理牌。保留每张牌的 React 身份，按手牌容器内部位置计算位移，浏览器原生动画执行线性平移；不把屏幕 X 当作桌面坐标，不重播淡入。触摸／指针开始、切桌、换决策、断线、页面隐藏、窗口或朝向变化、减少动效及卸载取消位移。新增逻辑没有逐帧 JavaScript 循环或额外服务器计算线程。

## 参考证据

参考普通实时客户端：[固定版本公开资源](https://game.maj-soul.com/1/v0.11.252.w/code.js)。本轮核对既有本机只读解码缓存，SHA-256 `5308fe6d3ab8bb8b0c8ab283e75176f839de9723d67179d00abeb15e6a39ff4f`；在线读取该资源本轮不可用。普通开局在 1200 ms 调用理牌；手牌位置间隔 2.55，更新速度为 `2.55 × 25`，对应每牌位 40 ms，线性移动。本项目按本地牌位间隔换算，未复制厂商程序或素材。

仍未对齐：厂商默认会排序全部 14 张并把最后一张视觉分隔，本项目保留真实第 14 张摸牌的逻辑身份和分隔，当前只排序原始 13 张。完整入场的材质透明度与高度缩放、厂商服务端发牌协议、真实 Android、完整规则和音画、生产认证 WSS 故障验收均未完成。不能把本轮记录当作整个目标完成。
