## 行为与参考范围

庄家理牌后，真实摸入的牌可能排到手牌中间。此前双击桌布仍打真实摸牌，画面最右侧的分隔牌留在原位。本次直接从与手牌渲染相同的 `handRack` 取视觉末张，精确匹配服务端当前合法弃牌 Choice，并以最右侧相同实体作为动画起点。普通摸牌仍打独立的摸牌，碰后仍按当前手牌末张操作。立直及鸣牌选择时双击只退出选择；不能构造不存在的操作。

依据已缓存官方客户端固定版本 `v0.11.252.w/code.js` 的普通 NewGame、LiPai 与 onDoubleClick 路径：理牌后 last_tile 指向视觉末张，双击使用它。仅在忽略审计目录读取，仓库不含厂商代码或素材；不是对当前最新客户端的完整验收。

参考客户端同时发送 `moqie=true`。本项目仍保留真实摸牌身份，视觉末张不是实际摸牌时只使用引擎提供的普通弃牌值，不伪造 `_`。**实体选择已靠齐，开局摸切协议及计分语义是否需要改变仍需进一步核对**，本次不宣称完全等价。
