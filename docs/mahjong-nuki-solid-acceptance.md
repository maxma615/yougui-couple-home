# 拔北实体牌验收

日期：2026-10-07。范围是公开北牌托盘与拔北飞行的实体质感，不修改规则、牌墙、累计数量或补牌时机。当前正式站仍为 `2a614ff`；本步先完成本地验收，再以实际发布记录确认上线。

## 问题与实现

隔离真实三麻流程已走通碰牌、弃牌、拔北、补白牌和自摸结算；拔北后的计数与北牌没有消失。但基线托盘和飞行只有牌面，实际观察的实体和侧面数量均为0。该差异与用户要求的实体麻将质感不符。

托盘现在复用已有牌面向上的六面牌体，包括牌面、底面与四侧，以及落桌接触阴影。牌体厚度为实际高度的0.4倍，牌面抬高同样深度；原托盘占位和三家旋转保持。牌面使用现有获许可的标准日麻素材，移除北牌旧的金色假厚度阴影。

拔北飞行复用已有实体飞牌，从本家唯一已知北牌的实际几何移动至新槽位的抬高牌面，插值深度与材质。目标牌面和整块牌体同时隐藏，结束、取消及卸载恢复各自原有可见性值和优先级；补牌入场仍等待230ms提取动画。重复北牌或其他玩家的隐藏来源不会被猜测，仍使用目的地强调。

## 对齐边界

这项实体建模依据用户要求和本产品已有碰杠/河牌质感。现有官方公开参考未提供已核实的拔北逐帧流程，不能称此厚度、材质与230ms完全等同雀魂。
