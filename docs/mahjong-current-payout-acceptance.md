## 为什么更新验证

旧 `mahjong-settlement-payment.tsx` 挂载未经过结算序列适配器的引擎快照，按钮仅记录点击；还使用旧 CSS 清单、旧“当前”标签与旧滚动容器。现版实际是每位和牌者的详情、一次本局总收支、全席确认后下一手。历史通过值不能证明当前流程。

现在每个浏览器和尺寸都重新创建真实物理牌墙，并重放逐个核对为合法的引擎 Choice。只允许测试播种上一手已有的本场和立直棒记账；不修改和牌数据或结算视图。真实引擎经过生产 `SettlementSequenceGame`，挂载生产 `GameRoom`；浏览器点击触发真实适配器 respond。双荣从第一位和牌者开始，逐页遍历，不从已经支付第一笔的旧快照开始。

未指定手牌的四麻物理牌池现在按确定顺序构造，保留整副牌及赤五守恒，避免重新创建的同一测试局产生另一组随机响应 Choice。这仅是测试牌墙变化。
