# 连续出牌动效验收

日期：2026-10-07。本记录验收手牌到河牌的连续动效及交互边界；完整雀魂体验目标仍在进行。已实际发布到既有ECS；以下记录源版本、验证与保留结果。

## 实现行为

- 两次点击同一实体或拖到桌心后，提交原始合法Choice。确认后的新增河牌才触发动效；同脸牌使用被选中实体的位置，不猜测另一个副本。
- 对手从上一帧公开牌背架起飞，随后显示已公开的弃牌。起点与河牌终点都保留本地尺寸、组合旋转和缩放；立直横牌及拖牌的轻微倾斜不会被当成未旋转矩形。
- room/game/hand/seat/index标识用于去重。HTTP与Socket重复、刷新及重连基线不会重播。已被叫走的牌取消飞行，河牌实体不重复保留。
- 断线、隐藏页面、减少动效偏好、视口/方向/全屏/牌桌尺寸变化取消飞行并恢复已确认目标。请求尚未返回时改变环境，旧起点也作废。同版本安静同步不打断已有动效。
- 断线时禁止旧动作按钮、选牌弹窗和手牌提交。合法拔北后北牌托盘和累计数量持续保留；立直、拔北、吃碰杠、自摸、荣和及过仍按引擎实际选项出现。
- 继续使用已固定授权的标准日本麻将牌面。230ms是本产品参数，未宣称它是雀魂公开时长；官方视频探查未取得可用于逐帧量化的实局画面。
