# 连续出牌动效验收

日期：2026-10-07。本记录验收手牌到河牌的连续动效及交互边界；完整雀魂体验目标仍在进行。当前为已验证候选，ECS发布信息在实际完成后追加。

## 实现行为

- 两次点击同一实体或拖到桌心后，提交原始合法Choice。确认后的新增河牌才触发动效；同脸牌使用被选中实体的位置，不猜测另一个副本。
- 对手从上一帧公开牌背架起飞，随后显示已公开的弃牌。起点与河牌终点都保留本地尺寸、组合旋转和缩放；立直横牌及拖牌的轻微倾斜不会被当成未旋转矩形。
- room/game/hand/seat/index标识用于去重。HTTP与Socket重复、刷新及重连基线不会重播。已被叫走的牌取消飞行，河牌实体不重复保留。
- 断线、隐藏页面、减少动效偏好、视口/方向/全屏/牌桌尺寸变化取消飞行并恢复已确认目标。请求尚未返回时改变环境，旧起点也作废。同版本安静同步不打断已有动效。
- 断线时禁止旧动作按钮、选牌弹窗和手牌提交。合法拔北后北牌托盘和累计数量持续保留；立直、拔北、吃碰杠、自摸、荣和及过仍按引擎实际选项出现。
- 继续使用已固定授权的标准日本麻将牌面。230ms是本产品参数，未宣称它是雀魂公开时长；官方视频探查未取得可用于逐帧量化的实局画面。

## 实际验证

- 完整37文件、300项单元与集成测试通过，包含真实备份恢复。首次六个备份测试因pg_dump未在PATH失败；加入本应用已有Postgres工具目录后完整复跑通过，未跳过恢复测试。
- Chromium/WebKit共84个真实SanmaGame/RiichiGame快照几何场景通过，覆盖三/四麻、三种横屏尺寸、所有相对席、普通切牌及立直摸切；暂停实际浏览器动画核对起点、中途路径、终点和旋转占位。另14个拖牌姿态、请求中旋屏及取消边界检查通过。每个场景使用新文档，避免多个React实例/旧事件状态互相污染。这些快照几何证据不冒充真实Socket。
- 26个麻将浏览器回归通过；其中新增4个真实Socket双会话用例验证三/四麻双方收到同一飞牌事件。20个实际服务Socket流程、6个显示/接口流程范围分别记录；显示夹具显式建立测试连接握手，不再以断线状态测试可点击合法按钮。
- 五份实际CSS、32种桌面/手机尺寸、三/四麻及重连压力布局通过，真实素材解码、公开北牌、副露、五种回应按钮及错误提示保持可见。
- 类型检查、生产构建通过，Build `SRSZBYgvZuX5SJW6Tjj11`；360个构建文件秘密扫描通过。
- 独立审查未发现阻断问题；其独立tracker10/10通过，11个产品文件SHA经根任务再次逐个对比一致。独立审查没有宣称执行浏览器、Socket或构建。

## 完整目标尚未满足的部分

真实Android实机尚未验收。牌桌整体构图、鸣牌/和牌反馈与雀魂实局时序仍要进一步观察验证。雀魂官方2023公告确认存在SHA256牌山验证，但闭源RNG、盐、牌山编码及揭示协议未得到可核实的一手说明；当前没有以猜测替换已测试的实体牌墙。没有把此动效步骤当作整个目标完成。
