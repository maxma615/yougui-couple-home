# 立直与和牌声明反馈验收

2026-10-08。本阶段本地实现与唯一独立审查修复完成；**尚未发布，当前线上仍为 a258986**。Linux 候选、受保护发布、公网 TLS 与主目录同步仍是必要门槛。

## 本地结果

原生结算开始即公开全部赢家的席位与和牌方式，不新增其他人的手牌/役种详情。所有 view 返回独立副本，每位观者的详情翻页及最终全员入账屏障保持原样。真实立直弃牌、首次荣和/自摸结算可触发桌边声明与原创本地提示音；原生加杠抢和及三麻普通/国士/双家抢拔北均覆盖。

多家荣和的桌边文字同在300ms出现，声音按赢家次序错开；卡顿释放多个到期回调时仍按实际播放时间保留至少30ms间隔。正常首位赢家声明到1200ms结束后才显示详情，确认时钟对应增加1200ms，后续赢家不重复等待。刷新、冷挂载、断线重连、版本跳跃、非法声明不补播；静音/尺寸变化/离开牌桌取消待播声音。

历史参考为缓存官方 `showRong/showZimo` 的300ms声明、200ms进场、1200ms结束和300+30*i的荣和声音时序。新文字与声音为原创实现，未使用厂商图片、字体资源、录音或代码作为产品资产；不表示核对过当前厂商版本。
