# 共享牌桌透视：合成帧验收

日期：2026-10-07。连续雀魂体验目标仍 active；本项恢复 WebKit 与 Chromium 的共享透视桌面，不把单项通过当作整体完成。

## 实际原因和修改

先前 WebKit `Page.snapshotRect` 普通截图把 `perspective(150cqh) rotateX(28deg) scaleX(.94)` 画成偏斜平面，虽然 DOM quad 已是梯形。最小矩形排除了 cqh、容器及父级 filter/overflow 等变量；headed 的同一截图 API 也复现，因此它不是独立的合成帧证据。

同页 `recordVideo` 经 `Screencast.startScreencast` 的录像帧保留正确梯形，各色块与 DOM 位置一致。这一新证据推翻了把软件快照误画推广为实际 WebKit 显示失败的判断。本次仅删除 `mahjong-camera.css` 的 WebKit affine 及其配套锚点覆盖，让两引擎使用相同桌面投影。本家公开副露与累计 North 仍在桌面上，隐蔽手牌和 HUD 仍在独立触摸区。

当前 camera CSS SHA256：`aa09c6ca9cae08151e139af6ee858da84cebc623d231e12a62fc9bb99817eb97`。

## 红到绿与画面证据

`tests/browser/mahjong-table-paint.tsx` 渲染真实 SanmaGame/RiichiGame 的 GameRoom，三麻夹具先实际执行合法拔北并确认累计 1 张。Chromium 使用无损截图；WebKit 使用同页独立合成录像末帧，另外保留软件截图作诊断。四个测试色块只存在于测试 DOM，不进入产品或素材。

- 修正前：Chromium 6 场景通过；WebKit 6 场景仅因平面 near/far=1 失败。
- 测试强制透视的诊断：12/12 场景和 48 个 DOM/paint 中心检查通过。
- 删除回退后的真实 CSS：12/12 场景和 48 个中心检查通过，无测试覆盖 CSS。
- 两种规则 × 三种视口（667×375、844×390、1440×810）× 两引擎；近远边宽度比须 >=1.1。
- 色块中心必须实际处于自身颜色连通分量，至少 50 个像素；无损色块还须 RGB 最大误差 <=10，质心 <=1.5 CSS px；VP8 色度抽样帧质心 <=2 CSS px。本轮最大质心误差 1.574 px。
- 奇数视口不改变布局；录像画布向上补齐到偶数尺寸，保持原点和原比例，解码尺寸也逐一断言。

判据使用从采样中心开始的颜色连通分量，避免附近 North 蓝色字形等同色素材污染质心。调试时已实际发现这类污染，修正测试算法后重新完成红到绿；并未通过隐藏牌或放宽到几十像素规避透视错误。

原始诊断、帧、录像、JSON 和终端日志保留在 ignored `.local/audit/`。OS 单窗口捕捉尝试因本机捕捉服务失败而未获得画面；没有调整系统权限，也没有把失败捕捉当作成功证据。

## 回归结果

- 单元/集成：345/345（42 文件），包含权限、持久化、迁移、备份恢复、North、和牌和客户端事件顺序。
- 两次前置测试失败保留：第一次工具 PATH 缺少 pg_dump；加入应用自己的工具路径后，高并发 42 workers 的已有 socket mock 时序用例失败。与上一轮相同的 maxWorkers=2 完整门禁最终全部通过；未改业务或测试源绕过它。
- 桌面投影：12 场景及 24 飞牌几何端点。
- 本家公开实体：84 个真实引擎视角/视口案例、三个 before/after 阶段，另有 8 个挂载详情交互。
- 手牌通道：160/160；真实引擎 before/after：24 对。
- 混合副露空间：576/576；普通布局：32 场景及 24 部分副露占位。
- 暗杠实体：84 个真实引擎视角/视口案例。
- 新 CSS 类型检查通过。真实 Socket/浏览器完整回归 26/26 通过（两浏览器），测试数据库和附件实际清理；本地构建 exit 0，Build `n5a-hCN2P35lW1vSWt1KX`；恢复配置后的类型检查及 360 构建文件秘密扫描通过。独立代码审查无 Critical/Important，文档 Minor 已修正；独立捕捉路径复核同样 12/48 通过（真实 CSS，无强制透视覆盖），667×375 的独立边缘标记证实 668×376 录像仅右/下 padding、没有缩放；实际发布继续进行。

独立飞牌探针用实际 DiscardFlightLayer 的 0/230ms、纯平面 homography 和两个方向，Chromium/WebKit 共 12 录制帧。DOM 中心对预期最大误差 0.018 px；小色块压缩帧质心最大 2.16 px；此独立粗粒度诊断不替代完整参考产品逐帧时序验收。

## 边界

本机自动化 WebKit 合成录像不是安装版 Safari、iOS 或真实安卓设备验收。授权标准牌面已使用，操作仍来自服务端合法 Choice，North 仍累计展示。雀魂服务器 RNG/验牌编码没有公开可复算输入；完整鸣牌/立直/和牌等参考时序与 Android 实机仍未完成，不据本项宣称全部一致。
