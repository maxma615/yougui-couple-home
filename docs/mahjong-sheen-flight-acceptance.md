## 修复行为

原有宝牌光泽只覆盖牌桌与手牌，移到页面独立动画层的牌失去光泽，落地后重新出现。本步让赤宝牌和公开指示对应的宝牌在出牌、被碰走及拔北的实体动画中继续显示光泽。读取实际原生 CSS 动画的当前时间，以本机 performance 时钟延续到运动牌和隐藏终点；落地使用同一持续推进的时间，避免从头闪一次。出牌未落地便被碰走时，沿用正在推进的牌河终点光泽并取消旧出牌动画。

普通非宝牌、牌背、HUD与预览不新增光泽。只使用公开指示；没有新增游戏指令字段、计分规则、服务端任务或 JS 每帧循环。实体尺寸、牌桌相机、出牌轨迹、取消保护和声音回调保持。此处继续使用原创 CSS 光带，不宣称厂商 UV 材质、速度曲线或逐帧一致。
