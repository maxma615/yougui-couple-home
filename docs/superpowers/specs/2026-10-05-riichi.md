# 有归 · 日本麻将四人联机

用户于 2026-10-05 批准先开发日本麻将四人联机，并明确要求按需启动、不持久化牌局。代码开源，项目选择优先依据适配与规则能力。

## 使用

普通成员进入 `/mahjong`，选择东风战或半庄、创建牌桌并发送房间码；其余三位成员输入房间码加入，四人准备后房主开局。玩家可来自不同情侣空间；管理员账号不占席位，不能读取手牌。复用现有手机号/密码登录，不添加公共注册。

四人真人对局，25000 起始点、每门一张赤五、无延长战，保留规则引擎默认连庄与流局规则。支持摸牌、切牌、立直、吃碰杠、自摸、荣和、流局、结算及再开一场。所有合法操作、牌山和计分由服务器的 @kobalab/majiang-core 1.4.1 负责。客户端只能发送服务器提供的选项编号，不能指定牌山或其他人的操作。

## 生命周期

麻将是网站进程自动启动的独立子进程，创建/加入牌桌时启动；查看空大厅不会启动。房间与牌局只保留在子进程内存，不建麻将数据库表、牌谱文件或恢复快照。账号、情侣空间与照片仍按原方式持久化。暂无牌桌或所有牌桌无连接且无操作满 10 分钟后清理牌桌；全部房间清空并空闲 10 分钟后退出麻将进程。短暂断线或刷新不会退出座位。页面明确说明服务重启或长时间全员离线会结束当前对局。

## 权限与可靠性

HTTP 操作及 Socket.IO 连接校验真实服务器会话和 member 角色，定期撤销停用/失效会话。推送仅包含本人暗牌、四家的公开河/副露、比分、宝牌指示牌、轮次与自己的合法操作；不得推送完整引擎模型、牌山、他人暗牌或未公开里宝牌。房间码随机八位，限制猜码与频繁操作。每人最多一桌、最多四位；非成员无法读桌或行动；开局后不能加入替换玩家。命令有 nonce 和决策阶段编号，重复提交不重复切牌、旧操作不能影响下一阶段。并发启动只生成一个权威游戏进程，不开放 Docker 控制权限。

手机竖屏可摸切牌并操作吃碰杠；暗牌横向区域可滚动但整页不能溢出。保留电影感，麻将界面以清晰可读和触控为先。连接中断显示提示，恢复后获取本人当前状态。游戏入口不改变原情侣空间权限。

## 验收

真实规则引擎单元测试覆盖合法操作、隐私、立直/胡牌/流局计分；独立测试数据库与四个独立浏览器会话验证跨空间入桌、准备、开局、实时同步、刷新重连、第五人/停用账号拒绝。按需进程测试验证空大厅不启动、并发唤醒单实例、空闲退出以及重启后没有旧牌局。回归原账号与照片持久化/备份恢复，构建及 Linux 部署检查不省略；手机浏览器自动化不冒充真实安卓机验收。
