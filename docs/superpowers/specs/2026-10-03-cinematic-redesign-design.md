# 有归整站重构：深色电影感

日期：2026-10-05。状态：设计与实施范围获批准。用户最新指定由 Codex 与子代理直接开发，不再交给 Claude Code + GLM。

## 目标与依据

为两位主要使用安卓手机的成员重构全部前端，保留可用的账号、邀请、日历、纪念日、待办、照片与实时更新功能。用户要求整体设计有品质、动效有表现力，拒绝奶油白、墨绿、陶土色，明确选择深色、电影感。

用户最终选定参考：Monolith Hero 的深夜光影、Nature Portfolio 的摄影展示，以及 Unseen Studio 的柔和艺术空间。界面称呼由“情侣小屋”统一改为“情侣空间”，品牌名“有归”保留；已有用户自行命名的数据不自动改写，内部 home 路由和接口不变。参考用于构图与交互，不复制其品牌、照片、字体文件或代码。

## 视觉语言

背景近黑 `#0D0E15`；内容层 `#171923`；浮层 `#222430`。主文字冷白 `#F5F2F6`，次文字 `#AAA7B8`，细线 `#30313F`，操作强调使用少量淡紫 `#D2C4E8`。此色板按用户追加的 Unseen Studio 参考落地。颜色以最终页面对比度检查为准，普通正文至少 4.5:1。

照片保留原色，以渐变遮罩为叠加文字提供阅读背景。无照片时使用低对比光影和文字构图，明确引导上传，不伪造双方回忆。全站不依赖外部图片或外部字体加载。

中文标题使用系统宋体族、正文使用系统无衬线族，跨平台有明确回退。标题以大字号、较松行距和小规模细节形成层次；正文清晰，不用过细字重。数字、日期采用等宽数字特性。桌面首页主标题 64–80px，手机 36–44px；正文 15–16px。

主视觉宽阔、构图有留白；深色空间中加入柔和淡紫光影、拱形建筑与水面倒影的原创装饰性场景，照片以错落展示和主图切换形成空间感。场景不冒充用户回忆；无照片时同样完整，不只有一片渐变背景。主要内容使用细线、文字行和照片区域分组。功能容器圆角 18px，输入框 10px，减少嵌套卡片。图标统一 Lucide，装饰性图标不代替可理解的操作文字。

## 手机与电脑布局

手机使用五项底部导航：首页、日历、待办、相册、我们。纪念日从首页显著入口进入，也在“我们”页有固定入口。现有 URL 保留；纪念日页面激活“我们”。底栏兼容安全区，内容底部留足空间，主要触控区域至少 44px。

电脑使用窄侧栏与宽内容区域，六个原有业务入口均可直接到达。布局用单一断点体系：小于 768px 手机，768–1099px 紧凑布局，1100px 起桌面。320px 宽仍可完成核心操作，无水平滚动。

## 弹窗与输入

修改密码只在按下“修改密码”后打开弹窗：当前密码、新密码、确认新密码；错误在字段旁显示。手机弹窗适配键盘和滚动，桌面居中；支持关闭、Escape、焦点管理、关闭后回到触发按钮。提交时禁止重复操作；成功遵循现有会话更新/重新登录规则。

姓名字段在输入时允许完全清空；初始化默认值只设置一次，不从保存值反复回填。必填校验在提交时执行，失败保留输入。空间和成员名称编辑遵循现有服务端权限，界面不扩大成员权限。

删除弹窗显示对象名和后果；冲突继续展示服务器版本与本人未提交输入，用户决定如何继续。

## 动效

首次进入页面：标题与主视觉淡入并上移 8–12px，300–450ms。功能区只执行一次，后续实时刷新不重新播放整页动画。

照片悬停轻微放大 1.025 倍；按钮按压缩放 0.98，120ms；筛选状态与导航指示 180–220ms；弹窗遮罩淡入、面板短距离进入 220–280ms。完成待办用短促勾选反馈，失败恢复原状态。

避免持续闪光、滚动劫持和全站重型 3D 场景。`prefers-reduced-motion` 下去掉位移与缩放，以即时状态切换保留功能。安卓低性能设备同样能直接操作，动画不阻塞点击。

## 前端结构与数据边界

保留 Next 路由、现有数据 DTO、API、鉴权、SSE 和版本冲突接口。重构 AppShell/PublicShell、统一基础组件、页面构图和样式组织。整理 globals、home、experience、public-experience 多层覆盖为一套 token 与组件样式，移除被替代的装饰，不叠加另一套末尾覆盖。

功能基础组件包括按钮、输入、字段错误、页面标题、空状态、资源操作和模态框；摄影展示、日历、待办各自保持独立内容组件。公共壳不读取受保护业务数据，照片仍通过鉴权接口加载。不调整数据库模式，不引入新的服务器依赖。

保留已有未提交功能改动，逐文件核对后整合。不修改学术工作台和根目录工程配置。本轮完成本地预览，不自动发布 ECS。
