# 本家公开牌进入共同桌面

持续目标与现有发布授权保持。当前真实在线596f3cb；本轮本家副露及北牌从平面手牌区域移入共同物理桌面，姓名/查看按钮、手牌及动作保持正常交互。本家公开牌仍在近端右侧，北牌在本家河牌旁的近端空位，不复制牌、不改变规则/洗牌/DTO。

先断言旧产品自己的声明牌和拔北不在共同桌面（组件RED两项，另真实规则浏览器RED），再分离 PlayerPanel 的实体部分与平面身份。CSS只新增相机层中的本家位置，不重新居中闭手；边界、投影实际内部采样及手牌/河牌遮挡按三/四麻、各座位、两浏览器及短横屏验证。现有布局回归须迁移旧选择器，不能跳过本家公开牌。

验证实体牌池及合法nuki/ankan到补牌、累计北牌静默重渲染、暗杠两背两面赤五和身份查看不发Choice；再跑完整单元、联机/显示、现有布局/飞牌、类型与构建。代理只负责新增真实引擎浏览器脚本，root负责产品和整合。主目录基线与每轮owned范围单独记录，禁止覆盖其它任务。

WebKit当前仿射回退和厂商精确相机/动效参数仍未证明；自己的声明牌共面是进展，不能标记整体完成。服务器已有多层历史镜像及3.8GB余量，本轮先形成可验证本地源码，发布前核对空间并复用保护发布器及备份，不盲删镜像或反复占用服务器编译。
