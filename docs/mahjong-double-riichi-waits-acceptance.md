# 双立直听牌计役修正（2026-10-09）

原生三麻、四麻结算已区分普通立直一番与双立直两番；听牌分析只读取公开的立直布尔值，两种情况都算成一番，导致十三番边界的役满反馈偏低。本次把请求者已宣告的真实立直番数，以及当前合法立直选项对应的番数，传入听牌分析。四麻按请求者的风位读取原生 `_lizhi`，三麻按实际席位读取；首次摸牌未受副露等打断时提供双立直，三麻拔北打断资格。

`GameView.ownRiichi` 只包含请求者的 `han` 和当前允许宣告的 `declarationHan`，均为0、1、2。没有立直选项时后者为0。其他玩家的公开对象不增加私有字段，不返回引擎数组、牌山或他人手牌。旧视图缺少此字段时继续使用原有普通立直语义。此修改不增加服务端听牌计算，不改变结算规则。
