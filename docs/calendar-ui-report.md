# 共同日历 UI 实施报告

日期：2026-09-23

## 已实现

- 新增共同日历月视图：周一开始、固定 42 格、跨月日期、当天与选中日状态、每日事项提示和选中日列表。
- 新增日程创建、详情、编辑和带名称确认的删除流程，支持全天事项与带时刻事项。
- 全天结束日期按包含当天展示；带时刻事项的控件和详情明确使用北京时间（Asia/Shanghai）。
- 编辑现有带秒或毫秒的事项时，若未修改时间，只改其他字段会保留原始时刻精度。
- 409 冲突显示服务器最新内容与本地草稿，可载入服务器内容或基于最新版本重试；草稿不会被后台刷新卸载。
- 月份导航与日期控件复用公共范围 `0002-01-01` 至 `9998-12-31`，边界按钮和越界相邻日期不可操作。
- 首页新增近期四条日程摘要；桌面侧栏和手机底栏新增日历入口。手机底栏共六项，窄屏无横向溢出。
- 日历读取沿用小屋 SSE 更新和失败退避机制，不新增模拟数据或独立刷新通道。
