# 手机竖屏横向牌桌与输入坐标

2026-10-10，本地候选已完成验证，尚未发布；当前 ECS 仍运行 `2cc2f94`。完整雀魂体验对齐目标仍在进行。

## 行为

手机触摸设备在竖屏且视口宽度不超过 1024 px 时，牌桌自动横向展示，不要求浏览器支持方向锁，也不再以竖屏提示遮挡牌桌。进入全屏仍尝试原生全屏与方向锁；手动旋转后恢复自然横屏，旋回竖屏再自动展示。离开时只释放本牌桌持有的全屏和方向锁，异步返回和外部全屏转移维持原有保护。

旋转只发生在牌桌外层，共享透视相机、牌桌与实体牌模型保留。HUD、选牌区、安全边距和弹窗使用横向逻辑尺寸；浏览器顶层的桌布与副露弹窗独立居中旋转，避免祖先变换失效后偏出屏幕。

拖牌在按下时冻结原始手牌区和牌桌坐标。预览位移、离开手牌区的判断和动作按钮排布使用逻辑横屏坐标；命中测试仍使用浏览器真实 `elementFromPoint` 和物理指针坐标。20 px 拖动阈值、合法 Choice、真实摸牌身份和出牌意图保持。拖回、取消、断线及旋转中断不会提交迟到的出牌。窗口尺寸、方向或全屏变化会清除尚未完成的桌布双击，防止旋转前后的两次点击拼成一次操作。

## 实际验证

- 完整单元／组件／集成：1246 项，106 文件通过。
- 本机 Linux 选择集：831 项，50 文件通过；这是本机选择集结果，尚非 ECS 同镜像结果。
- 类型、生产构建与 374 个构建文件秘密扫描通过。
- 274 个原生浏览器场景通过，并逐份核对当前源码摘要。竖屏 150 场景：8 个 Chromium／WebKit 三／四麻方向、二次点按、桌布弹窗与退出；42 个 Chromium CDP 可信触摸拖牌、边界、拖回、取消、断线和旋转；12 个两浏览器立直、拔北及响应布局；24 个真实规则与 RoomStore 双荣和详情、收支、ACK 与下一局；64 个真实 RoomStore HTTP／Socket 开局、消息顺序、两种传输、声音和自动出牌。自然横屏回归另有 36 个可信触摸、24 个动作布局和 64 个真实联机开局。

响应布局压力场景显式使用组合 Choice 注入，只证明布局和点击；真实拔北、结算与联机开局使用规则引擎。浏览器全屏和方向锁是受控边界，不代表真实 Android API 验收。WebKit 拖牌目前由点按与界面场景覆盖，可信触摸拖动证据来自 Chromium CDP，不能称作 WebKit 原生触摸拖动验收。

实现前方向测试 3 项失败／9 项通过；新增桌布中断测试 4 项失败／12 项通过。首次完整回归失败包括旧测试仅模拟 `top` 的不完整 DOMRect 和本机缺少 `pg_dump` 路径，补齐完整几何与已安装 PostgreSQL 18 工具后 1246 项通过。弹窗测试实际发现旋转后居中偏移并修正；结算比较改用真实旋转后的逻辑方向，仍保留视口内、原生命中、最小目标、滚动和真实收支断言。

证据位于忽略目录 `.local/audit/portrait-screen-final/`：`native-proof-index.json`、`linux-local.json`、`review.json` 与 `review.txt`。后者为根任务自审，不是独立审查。完整日志 `portrait-screen-full-r03.log`，类型 `portrait-screen-type-r04.log`，构建 `portrait-screen-build-r03.log`，秘密扫描 `portrait-screen-secrets-r02.log`；最终原生矩阵日志分别为 `portrait-screen-native-r05.log`、`portrait-touch-native-r02.log`、`portrait-action-native-r02.log`、`portrait-settlement-native-r02.log`、`portrait-opening-network-r02.log` 与自然横屏回归日志。

## 参考与剩余范围

当前官方入口读取为 Unity WebGL 4.0.47 启动页，包含竖屏旋转和输入映射；本项目使用自己的 DOM／CSS 与坐标实现，没有纳入其代码或素材。观察启动页不能证明完整当前游戏体验一致。当前版本的 16:9 适配、世界尺度、完整音画时序、开局摸切标记协议、真实 Android／GPU 和生产认证 WSS 故障仍待逐项核对。共享相机不依据已知软件截图偏斜修改。

候选不修改规则、计分、洗牌、电脑计算预算或业务数据。生产发布须继续核对父版本、同镜像受限 Linux、活动真人牌局屏障、十二表摘要、清理器、资源限制、禁备份和公网文件摘要。未完成这些步骤前不宣称上线。
