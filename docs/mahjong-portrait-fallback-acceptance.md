# 手机竖屏横向牌桌与输入坐标

2026-10-10，运行代码 `4a238f0` / Build `auQA0gv8tyRMJGWlGn_an` 已实际发布。完整雀魂体验对齐目标仍在进行。

## 行为

手机触摸设备在竖屏且视口宽度不超过 1024 px 时，牌桌自动横向展示，不要求浏览器支持方向锁，也不再以竖屏提示遮挡牌桌。进入全屏仍尝试原生全屏与方向锁；手动旋转后恢复自然横屏，旋回竖屏再自动展示。离开时只释放本牌桌持有的全屏和方向锁，异步返回和外部全屏转移维持原有保护。

旋转只发生在牌桌外层，共享透视相机、牌桌与实体牌模型保留。HUD、选牌区、安全边距和弹窗使用横向逻辑尺寸；浏览器顶层的桌布与副露弹窗独立居中旋转，避免祖先变换失效后偏出屏幕。

拖牌在按下时冻结原始手牌区和牌桌坐标。预览位移、离开手牌区的判断和动作按钮排布使用逻辑横屏坐标；命中测试仍使用浏览器真实 `elementFromPoint` 和物理指针坐标。20 px 拖动阈值、合法 Choice、真实摸牌身份和出牌意图保持。拖回、取消、断线及旋转中断不会提交迟到的出牌。窗口尺寸、方向或全屏变化会清除尚未完成的桌布双击，防止旋转前后的两次点击拼成一次操作。
