# 桌面悬停预选与触屏确认（2026-10-09，本地候选）

参考已缓存的官方 v0.11.252 客户端行为：桌面默认 click_prefer=0，鼠标停留同一张牌超过10ms后预选；按下时固定是否已选中，释放时确认。click_prefer=1关闭桌面悬停预选，需二次点击；触屏不使用鼠标悬停。只参考行为，没有引入厂商代码、图片或声音。

## 实现

桌面默认悬停11ms抬起当前合法牌，下一次点击复用实体牌的原生Choice和出牌动画。触屏先选再确认。便捷操作中的“桌面二次点击出牌”可恢复两次点击，偏好保存在yougui.mahjong.confirmClick，默认关闭。按下即取消尚未完成的悬停，长按不会自行获得确认资格；触屏按下不能继承鼠标悬停选择。

只预选实际合法Choice对应的实体实例，重复牌仍按tileId区分；房间、席位、游戏、决定、立直模式和Choice集合改变会取消旧悬停。忙碌、断线、结算、摸牌未到位及拔北替换未显示期间不会预选。离开牌面、页面失焦/隐藏/退出、视口或全屏变化取消待定悬停。拖出牌桌仍沿用原来的实体测量与合法落点路径，没有修改相机、牌桌透视或规则引擎。
