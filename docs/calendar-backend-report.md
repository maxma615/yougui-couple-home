## 时间与显示契约

- 全天 `start/end` 为纯日历日期，结束日包含，允许同日。
- 带时刻输入必须包含 `Z` 或显式偏移；日期和时分秒严格验证，接受至毫秒精度，返回 UTC ISO。拒绝不含偏移、非法日期、24时、闰秒及无效偏移。
- 实际时刻判断结束不早于开始，允许零时长；日历按 `[start,end)` 显示，午夜结束不占第二天，零时长事项显示在开始日。
- 上海本地输入使用 `Intl` 指定 `Asia/Shanghai`，枚举附近偏移后严格回验。历史夏令时不存在/歧义时间明确拒绝。显式偏移 API 时刻仍可直接表达这些时段。
- 日历事项范围统一 `0002-01-01` 至 `9998-12-31`（带时刻按上海显示日期校验）。`MIN/MAX_CALENDAR_YEAR/DATE` 由 `time.ts` 导出。月视图周一开始、42格，邻接格可落0001/9999年，UI必须禁用这些超事项范围日期。
- `shanghaiDateTimeInput()` 返回分钟精度控件值。UI修改非时间字段时应保留未改动的原始 API 时刻，避免截断已有秒/毫秒；已告知界面任务。
- 日期事项列表先全天后开始时刻，并用ID稳定排序。首页近期列表包括正在进行的事项，排除已结束事项。
