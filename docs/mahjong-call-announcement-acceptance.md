# 角色与大字宣告验收

日期：2026-10-07。本次实现处于本地验证阶段，线上仍是产品4fba66d；发布结果将在实际核验后补充。整个雀魂体验对齐目标未完成。

## 参考与实现

在[雀魂官方频道的鸣牌节目](https://www.youtube.com/watch?v=288HgmhkMjg)取得真实连续画面：约911.54秒可见角色与「ポン」斜切宣告，约912.54秒恢复牌桌。第二次定向正常播放909.012–920.917秒，48个250ms采样均保存媒体时间、readyState及截图SHA；根任务实际查看前后帧。稀疏帧与播放器错误尾帧不作为动画证据。该片段支持角色、大字与斜切构图，不能证明牌河至副露存在连续飞行，也不能给出厂商精确持续毫秒数。

实现保留服务器确认后的反馈生命周期，增加独立actionLabel，避免从含分隔符的成员姓名猜动作。吃、碰、杠、拔北、立直、自摸、荣和、流局使用原创头像图集与大字斜切宣告，普通摸牌和出牌保留简短提示。标签、成员名字与无障碍文本分开；装饰不捕获指针。肖像沿用本产品既有原创768×768图集，不复制厂商角色、桌面或牌面像素；标准日麻牌面仍沿用原许可素材。

900ms继续作为本产品参数；特殊动作优先、重复快照去重、冷开/断线/重连不重播及北牌累计均保留。宽度46cqw（最大540px）、高度32cqh（最大250px）是当前产品构图选择，不称其为厂商精确相机或布局。减少动态效果时保留动作信息并取消扫入动画。

## 已执行验证

- Hook单测实际RED：缺少actionLabel导致13失败、5通过；组件实际RED：尚未导出组件导致5失败。实现后23项定向GREEN。
- 根真实浏览器探针实际RED：旧小提示条没有角色宣告。使用108/136实体牌墙与合法Choice推进吃、赤五碰、明杠，再挂载GameRoom；扩展后的36个两浏览器/三横屏尺寸用例GREEN（增加真实拔北、立直和拔北补牌自摸），核对标签、完整姓名、头像、字号、桌内边界、指针透传、过期、重复、冷开、断线重连和减少动态效果。首次WebKit观察早于被动effect提交失败；增加渲染后两帧的观察屏障，未更改产品期限或降低断言，最终36项全部重新执行，截图将CSS动画停在350ms稳定段，以免将淡入像素当作最终图层。
- 根最后完整测试367项/44文件通过，maxWorkers=2；包含现有成员权限、并发、本地持久化、迁移、备份恢复验证。
- 独立审查实际23项定向通过后指出流局无actor却配本家头像。根独立亦发现该问题，实际RED1/6后省略无actor肖像，GREEN6/6；审查者复核24项定向、源码摘要和diffcheck，Important解除。
- 联机回归26项通过（20真实Socket、6显示/API夹具），隔离数据库/附件已清理；该批先于最后无actor肖像两行修正。最后修正后根367完整、36渲染、生产build、类型检查与360构建文件秘密扫描均实际通过。生产发布尚未执行，不用上一版本结果替代本次结果。
