# M1 本地验收记录

日期：2026-09-23。环境：macOS、Node 26.9.0、PostgreSQL 18.6、Next 16.3.6。

M1 范围为双账号/邀请、小屋、纪念日、共同待办、点滴照片、同步/冲突、备份恢复。共同日历属于后续 M2。本地验证不等于公网部署或 Docker/Linux/真实手机验收。

## 功能与边界证据

- 真实 PostgreSQL 约束和事务验证最多两位成员、同邀请及不同邀请并发消费、一次性/过期邀请、无开放注册。
- 管理员 CLI 子进程实际初始化/重置；重复初始化拒绝；密码命令行参数拒绝；重置撤销旧会话；登录轮换当前旧令牌。
- 三类内容 CRUD、负责人同屋限制、重复完成幂等、过期版本409并返回同屋最新记录。
- 全路由HTTP权限矩阵覆盖未登录、伪造homeId、其他小屋账号、跨源写入；登录/邀请/密码达到阈值429，限流器过期恢复单元验证。
- JPEG/PNG/WebP真实解码与字节/像素上限；伪装/损坏/截断/路径输入拒绝；O_NOFOLLOW读取与私有不缓存响应。
- 照片正式移动、DB/版本/事件和失败补偿均受维护锁保护；删除清理队列可重试；未知/临时孤儿、符号链接、目录、断链、摘要不符分类。
- SSE真实连接、撤销关闭、游标重放/过期重置、事件与事务同提交、同屋发布顺序锁；UI在SSE失败时退避轮询，恢复在线立即刷新。
- 409两份内容对照；后台刷新失败不卸载编辑器；照片部分上传失败保留剩余File队列，无需重新选择即可重试。
- 真实pg_dump/pg_restore空数据库与附件目录演练；账号密码仍可登录，旧会话/未消费邀请失效；两种合法待清理状态正确识别；篡改/非空目标/失败标记受保护。
- 生产进程实际停止再启动，三类记录和版本/会话保留；重新登录可读取三种格式照片，全部SHA-256一致。

## 验证范围

使用隔离的 ch_ 测试数据库和应用目录内临时附件。没有向正式账号写入示例资料，没有创建远端仓库或执行公网部署。手机检查包括WebKit iPhone尺寸/非上海时区、390px窄屏冲突与草稿流程、截图人工查看及横向溢出断言。没有真实手机硬件验收。

当前机器未安装Docker；Compose构建、Linux容器运行、容器卷空恢复、维护脚本实际停启、DNS与HTTPS需要在明确授权的部署目标复验，不能据本记录宣称已验收。Compose脚本语法已检查；本地恢复测试实际调用PostgreSQL工具，非模拟返回。
