# 立直、荣和、自摸固定语音

日期：2026-10-09。连续体验对齐目标保持 active；这是声音反馈的一步，不能作为完整雀魂体验验收。

## 行为

此前三种宣告只有原创合成提示音。现在在浏览器音效首次通过真实手势解锁后，预加载本地日语短语音：立直「リーチ！」、荣和「ロン！」、自摸「ツモ！」。已加载的短语音替换同一宣告的提示音，不叠加播放。仍使用现有连续公开状态转换、宣告事件身份、桌上宣告标记与300ms起始时间；多家荣和保持30ms顺序间隔。没有从其他玩家的私有手牌推测宣告。

声音未加载好或加载失败时，当时的事件照常使用原有提示音。加载完成不自动播放，不补播锁定、静音、后台、断线或已消费事件。网络和解码整个加载最多10秒；卸载取消请求，迟到结果不进入已销毁播放器。下一次解锁可重试失败的预加载。保持原有0.32总增益、最多8个活动声源和静音/暂停/关闭资源清理。

生产服务器与浏览器只读取三段24kHz单声道PCM WAV，共87,742字节。没有安装或运行语音模型，没有新增后台推理、麦克风权限或外部语音API。

## 素材来源与复现范围

使用 [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M)，固定修订 `f3ff3571791e39611d31c381e3a41a3af07b4987`、公开日语音色 `jf_alpha`；生成包 kokoro 0.9.4 / misaki 0.9.4、Python 3.12，正常安装 UniDic。模型、配置与音色文件均按修订下载并核对摘要。生成时 CPU 两线程、interop一线程、速度1.15、输出24kHz PCM16。没有使用雀魂录音或克隆角色演员。

原始样本生成后，以峰值0.4%为有效区间，前后保留20ms/35ms，峰值归一到0.65，两端各5ms渐变。最终三段分别约0.699 / 0.546 / 0.581秒；输入文字、音素、原始与最终摘要、精确裁剪帧、模型版本及处理参数记录在 `public/audio/mahjong/voices/provenance.json`。未固定随机种子，因此不宣称重新生成会字节一致。

Apache 2.0全文与来源声明保存在 `public/licenses/Kokoro/`。模型权重、Python环境和原始生成缓存只在应用忽略目录，未纳入源码发布包。
