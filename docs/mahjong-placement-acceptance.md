## 行为

- 同一张实体手牌第一次点选抬起，第二次确认切牌；同面不同张不会误确认。允许拖到桌心切出，桌心外释放或 pointercancel 不出牌。服务端原始 Choice ID 保持不变，提交中、断线及决策变化清除临时选中。
- 河牌按六张可见牌排一行，立直横牌占真实横向宽度；被叫走的牌不重复显示，原引擎弃牌事件保留以维持振听，立直横牌标记传给下一张可见牌。
- 公开副露按来源显示横牌，加杠保留原被叫牌并在同一列叠第四张；红五仍是对应实体。吃牌支持被叫牌在顺子任意位置，选项预览显示三张完整牌。
- 保留已上线的北牌托盘和累计次数，以及只出现合法操作的动作区。

布局语义核对采用 majiang-core 1.4.1 和固定版本 Kobalab 公开 UI。这些来源不等于雀魂官方；暗杠暂维持四背，未宣称完成全部摆放对齐。操作方式参考雀魂官方启动指南第14页。
