# 吃、碰、杠、拔北语音与宣告时机

日期：2026-10-09。连续目标保持active。本步骤补齐动作宣告语音及抢和窗口中的字样，完整厂商体验仍未验收。

## 本次行为

七种日语固定语音中新增吃「チー！」、碰「ポン！」、杠「カン！」与拔北「ペー！」。与上一版本立直、荣和、自摸使用相同本地公开模型、音色、裁剪/渐变/归一化处理，四段共84,010字节，全部七段共171,752字节。来源、生成参数、音素和最终摘要记录在 `public/audio/mahjong/voices/provenance.json`；Apache 2.0许可证与声明随包保留。没有使用厂商录音、演员克隆或生产端推理。

动作宣告与牌落地声音分开：只有连续接受的公开状态能产生宣告，且必须匹配桌内同一玩家、动作种类和决策身份的宣告字样，才能开始播放。吃、碰、明杠、暗杠、加杠与拔北的实体牌动画及原有牌体声音保持各自时机。

检查发现此前三麻进入抢北/暗杠抢和窗口时，公开宣告没有立即显示。现在依据连续公开阶段与玩家公开信息显示“拔北”或“杠”，语音随字样开始，未读取其他玩家手牌。抢和窗口结束后，成功补牌只是实体动作，不重复宣告；若被抢和，保留先前真实宣告并进入荣和流程，不发出第二次成功杠/拔北声音，也不延长旧字样的900ms期限。

字样最多等待900ms；未加载好时该次动作语音跳过，原有牌落地声照常，不因下载完成补播旧宣告。保持10秒加载上限、静音/后台/GET/断线/卸载清理、8活动声源上限与0.32增益。浏览器只解码七段小型WAV；服务器不安装或运行模型。
