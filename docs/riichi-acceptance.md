# 有归 · 四人日本麻将验收

2026-10-06，本地冻结副本基于 `c00d3e0` 与日本麻将变更；另一轮未提交的全站动效不包含在此次版本中。

## 功能与来源

普通成员登录后打开 `/mahjong`，创建东风或半庄牌桌，把八位房间码告知另三位成员；四人准备后由房主开局。不同情侣空间可以一起打牌，每个情侣空间仍只有两名成员。无需额外麻将账号，管理员不能读取或参与牌局。

规则引擎固定为 [kobalab/majiang-core 1.4.1](https://github.com/kobalab/majiang-core)（MIT）。它负责发牌、吃碰杠/立直/胡牌合法性、振听、流局、连庄及符翻计分；项目自己的适配器负责真人决策和只发送本人暗牌的视图。没有引入 AI、Elixir/Rust/Z3 或其他常驻规则服务。

## 按需运行

- GET 空大厅不启动游戏。创建/加入时，由 Next 的服务器 API 启动应用容器中的 Node 子进程；不需要 Docker socket、服务器 root 权限或额外 Compose 服务。
- `MAHJONG_PORT` 默认 3100，为内部端口，不开放到主机公网。Caddy 仅将 `/mahjong/socket.io` 代理过去，其余仍是网站端口 3000。
- 房间/手牌/牌山只放在该进程的内存中，没有游戏表、牌谱文件或自动恢复。原账号、生活资料和照片继续按原方式持久化。
- 短暂断线保留座位；全员离线且无操作满十分钟后清桌。全部桌清空并空闲十分钟后退出游戏进程。网站父进程停止时，子进程也退出。
- 房主主动解散需要弹窗确认。网站升级、备份停机、重启或长时间全员离线都会结束未保存的对局。
