# 情侣空间功能页面动效

用户要求将首页的 Motion Sites / Stratum 动效语言延伸到其他页面。本次在已确认的深色电影感设计上，为相册、日历、纪念日、待办、设置及共享表单补齐动效，保持本地预览，未更新 ECS。

## 实现范围

- 共享页面标题使用遮罩上移，眉题、说明及操作区依次进入；设置区块、资料卡及表单在进入视区时揭示一次。导航选中背景平滑移动，按钮提供按压反馈。
- 页面容器不使用路由 key，不为播放动画重新挂载页面或表单。区块观察器只处理 DOM 新增及移除，不因 SSE 更新重播。键盘焦点进入、页面进入后台或启用减少动态效果时立即显示内容；退出页面时清理观察器及监听器。
- 相册封面与照片墙切换、日期分组、照片及缩略图有渐入和缩放；大图查看有打开与 220 ms 关闭过渡。保留原生 dialog、方向键浏览、Escape、遮罩关闭及关闭后焦点恢复。
- 日历换月按前后方向滑入，选日更新日程并提供短过渡。纪念日主卡及列表依次出现。待办切换筛选时列表渐入，服务端确认成功后显示勾选反馈及成功文案，失败继续回滚乐观状态。
- 设置成员、连线与资料区依次入场；共享弹窗打开、遮罩和关闭过渡统一。启用 `prefers-reduced-motion` 后停用上述动画和导航位移过渡。

## 同步正确性

审查时确认了两处晚到响应可能覆盖更新状态的情况，并在本次修复：

- 待办确认记录保存版本与完成态，只有它们与当前页面数据一致才显示成功文案及确认动画。较新的 SSE 更新不会显示旧状态的确认；失败回滚时清除该条待办的旧确认，避免重播先前的成功动效。
- 照片上传及删除采用函数式资源更新，并检查资源 ID 与版本。上传按照片 ID 去重；较新版本状态不被晚到响应覆盖。删除后的索引继续由现有照片数量校正逻辑处理。
- 确认动画完成后释放 `transform`，按钮继续保留按压效果。
