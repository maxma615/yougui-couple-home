# 情侣空间首页 Stratum 动效

用户于 2026-10-05 提供 Motion Sites 的 Stratum hero 提示词，要求把其中的动效用于现有情侣空间首页。此次沿用情侣空间的中文内容、照片入口与导航，将提示词的 VISION 视频及入场节奏接入首页。提示词要求保持本地，本次未更新 ECS。

## 实现

- 使用提示词提供的夜间门洞、水面场景。静图转为 WebP；视频转为 H.264/yuv420p、1920×1080、24 fps、8.041667 秒、无音轨，约 1.34 MB。媒体放在 `public/art/`，浏览器不请求外部素材站。
- 边框分段绘制，标题两行分别在 420/520 ms 后遮罩上移，介绍、按钮和页脚依序入场；按钮及眉题使用 400 ms 文字解码。中文随机字符保持全角字宽，固定控件布局，并保留稳定的无障碍名称。
- 桌面精细指针触发缓动视差；触摸设备不启用指针视差。视差收敛后停止动画帧循环。
- 视频静音、循环、内联播放。首屏离开视区或页面进入后台时暂停，返回时恢复。开启减少动态效果或 `saveData` 时不加载视频，静图持续提供背景。
- 原有照片封面、添加照片、相册及其他页面保留既有功能。没有数据库、账号、权限或服务端接口变更。

## 实际验证

- `npm run typecheck`：通过，包含新增浏览器测试的类型检查。
- `npm run check:clean-build`：最终源码副本构建通过，无环境文件、数据库地址、运行时密钥和附件配置依赖。
- `npm run test:e2e -- tests/e2e/home-motion.spec.ts tests/e2e/cinematic-ui.spec.ts`：Chromium 与 WebKit-mobile 共 16 项通过。
- 修正新测试的 DOM 类型及精确标题断言后，单独复跑 `tests/e2e/home-motion.spec.ts`，两端共 6 项通过。
- 浏览器实际解码到 1920×1080，播放时间推进，离屏暂停并恢复；桌面指针移动改变实际变换矩阵；首屏无横向溢出，流程无 `pageerror`。减少动态效果、省流量模式均未发出视频请求，照片封面与导航可用。
- 在用户的 Google Chrome 中登录虚构演示账号，实际打开 `/home` 并目视检查画面。另有约 13 秒的实际首页录屏，保存在忽略的 `.local/motion-preview/home-demo.mp4`。

移动验证使用模拟手机尺寸的 WebKit 环境；本次未在实体安卓手机上验收。
